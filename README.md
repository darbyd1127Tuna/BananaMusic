BANANA MUSIC
A music and social media frontend concept inspired by platforms like Spotify and Facebook. BananaMusic combines music and discovery, user profiles, social interactions, and modern responsive interface into one web application.
FEATURES:
Music player interface
Browse and discover music
Album and artist sections
User profiles
Followers/following interface
Social style feed
Interactive likes and social interactions
Responsive design for desktop and mobile
Interactive navigation
Css/Javascript animations and Ui interactions 

TECHNOLOGIES:
HTML5 - page structure and semantic markup
CSS3 - responsive layouts, animations, and styling
JavaScript - interactions, navigation, music-player functionality, and dynamic UI behavior
Git/GitHub - version control and project hosting
